# 🚀 5G 접속 및 클라우드 터널링 성공 기록 가이드 (v2.0)

본 문서는 일주일간의 난관을 뚫고 성공시킨 **'5G 환경 스마트 오더 접속'**의 모든 기술적 메커니즘과 해결 과정을 기록한 소중한 자산입니다.

---

## 1. 🔍 문제 정의 (Problem)
- **현상**: 매장 와이파이가 아닌 5G 데이터 환경에서 손님 폰이 맥북 서버를 찾지 못함.
- **에러**: `net::ERR_CONNECTION_REFUSED`, `1033 Error`, `404 Not Found`.
- **원인**: 파트너님의 맥북은 공유기 내부(Private IP)에 숨어 있어 외부(5G)에서 직접 접근할 수 있는 '공식 주소'가 없었음.

---

## 2. 🛠️ 해결의 핵심: '마법의 우체통' (Cloudflare Tunnel)
맥북 서버를 전 세계 어디서든 접속 가능한 **공식 서버**로 변신시켰습니다.

### ⛓️ 작동 메커니즘
1.  **터널 개통**: `cloudflared` 프로그램이 맥북과 Cloudflare 본사 사이에 **비밀 지하 통로**를 만듭니다.
2.  **공식 주소 생성**: `https://...trycloudflare.com`이라는 외부용 주소가 생성됩니다.
3.  **신호 전달**: 
    - 5G 폰 -> 공식 주소 접속 -> Cloudflare 본사 -> **(비밀 통로)** -> 파트너님의 맥북 서버
4.  **장점**: 맥북이 와이파이를 쓰든 랜선을 쓰든 상관없이 인터넷만 되면 고속도로가 유지됩니다.

---

## 3. 🧠 지능형 연동 시스템 (Smart Sync)
서버 주소가 매번 바뀌어도 폰이 알아서 찾아가는 시스템을 구축했습니다.

- **서버의 역할**: 실행 직후 터널 주소를 낚아채서 **Firebase 클라우드 게시판**에 즉시 보고합니다.
- **안드로이드 앱의 역할**: 켜지자마자 3초마다 게시판을 확인하여 터널 주소가 있으면 즉시 그곳으로 접속 경로를 변경합니다.
- **랜딩 페이지의 역할**: QR을 찍고 들어온 손님을 현재 활성화된 가장 빠른 경로(5G 터널 혹은 WiFi)로 자동 안내합니다.

---

## 4. 🛡️ 안드로이드 보안 빗장 해제 (Security Fix)
가장 큰 난관이었던 안드로이드의 까다로운 보안 정책을 해결했습니다.

- **현상**: 안드로이드 시스템이 클라우드(Firebase) 정보를 읽어오는 것을 '위험한 통신'으로 간주하여 차단함.
- **조치**: `network_security_config.xml` 설정을 통해 Firebase와 Cloudflare 도메인을 '안전한 구역'으로 명시하여 통신을 허용함.

---

## 5. 🏁 최종 완성된 시스템 사용법
이제 파트너님은 복잡한 설정 없이 다음만 실행하면 됩니다.

1.  **실행**: 데스크탑의 `starlink_start.command`를 더블클릭합니다.
2.  **확인**: 터미널에 `✅ 5G 보안 주소 생성 성공` 및 `Firebase 동기화 성공`이 뜨는지 봅니다.
3.  **영업 시작**: 손님이 QR을 찍으면 5G든 와이파이든 즉시 메뉴판이 열립니다.

---
